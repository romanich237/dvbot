## О проекте

DV Bot помогает участникам сообщества находить друзей по интересам. Бот работает на JavaScript, хранит данные в SQLite и поддерживает веб-приложение внутри Telegram. Названия корпусов, координаты, оформление и ссылки задаются в `config.json`.

Это обезличенная сборка: без исходной базы, пользовательских фотографий, токенов, идентификаторов администратора и каналов. В комплекте — нейтральный логотип. История Git не включена.

## Возможности

- Регистрация анкет с фотографиями, видео и описанием.
- Просмотр анкет, симпатии и взаимные совпадения.
- Личные диалоги и жалобы на нарушения.
- Управление пользователями, модераторами и рассылками.
- Статистика по корпусам и расстояние между ними, если указаны координаты.
- Mini App с анкетами, диалогами и административными инструментами.
- Автообновление из публичного GitHub-репозитория без токена.

## Требования

- Node.js **24 или новее** (используется встроенный `node:sqlite`).
- npm; Ubuntu для приведённых ниже команд.
- Токен бота из BotFather и числовой Telegram ID администратора.
- Для Mini App: домен, HTTPS, nginx и certbot.

## Быстрый запуск

1. Распакуйте архив и перейдите в каталог `dv_v2-template`.
2. Откройте `config.json` и заполните `token` и `adminId`. Username бота автоматически определяется через Telegram API (`getMe`) при каждом запуске.
3. Замените элементы `campuses` своими корпусами. Названия должны быть уникальными, до 50 байт UTF-8. Координаты необязательны. В комплектном конфиге указаны условные примеры — замените их своими или задайте `null`.
4. Установите зависимости и выполните проверки:

```bash
npm ci
npm run check
```

5. Запустите бота:

```bash
npm start
```

6. Напишите боту `/start`. Администратор может открыть панель командой `/admin`.

База `dating.db` создаётся автоматически, поскольку `createDatabase` включён. Токен хранится только в `config.json`; `.env` не используется. Не запускайте одновременно несколько экземпляров с одним токеном.

## Настройка config.json

| Поле | Назначение |
| --- | --- |
| `token` | Токен вашего Telegram-бота. Обязателен. |
| `adminId` | Ваш положительный числовой Telegram ID. Обязателен. |
| Username бота | Определяется автоматически через `getMe`; поля в конфиге нет. |
| `database` | Путь к файлу SQLite относительно проекта. |
| `photoDirectory` | Каталог локальных фотографий. |
| `createDatabase` | Разрешить создание новой базы при отсутствии файла. |
| `campuses` | Массив корпусов: `name` и `coordinates`. |
| `branding` | Название, организация и описание на публичной странице Mini App. |
| `supportLinks` | Кнопки ссылок в рассылках и приложении; `[]` — без ссылок. |
| `statsChannelId`, `statsMessageId` | Канал и сообщение для обновления статистики; `0` отключает публикацию. Боту нужны права редактирования сообщения. |
| `statsIntervalSeconds` | Интервал обновления статистики в секундах. |
| `adEveryViews` | Через сколько просмотров показывать рекламный текст, если он настроен. |
| `mailingDisableStars`, `mailingDisableMonths` | Параметры имеющегося механизма отключения рассылки за Stars. |
| `github.repository` | Ваш репозиторий `owner/repository`; пустая строка отключает фоновую проверку версий. |
| `github.branch` | Ветка обновлений. |
| `github.autoUpdate` | Автоматически устанавливать новые версии и перезапускать PM2. |
| `github.checkIntervalSeconds` | Интервал проверки версий, минимум 60 секунд. |
| `pm2Process` | Имя процесса; оставьте `dvbot`, как в PM2-конфиге. |
| `miniApp.enabled` | Включить Mini App; по умолчанию выключено. |
| `miniApp.url` | Публичный HTTPS URL вашего приложения. |
| `miniApp.host`, `miniApp.port` | Локальный адрес и порт сервера; оставьте `127.0.0.1`, порт — свободный. |
| `miniApp.initDataMaxAgeSeconds` | Допустимый возраст данных авторизации Telegram. |
| `miniApp.sessionHours` | Продолжительность сессии приложения. |

Пример корпуса (условные координаты; замените своими):

```json
{"name": "Главный корпус", "coordinates": [10.0, 20.0]}
```

Если расстояние не нужно:

```json
{"name": "Главный корпус", "coordinates": null}
```

Пример ссылки:

```json
{"text": "Новости проекта", "url": "https://t.me/your_channel"}
```

Используйте HTTPS-ссылки. После изменения конфига перезапустите процесс. Переименование корпуса не переносит старые значения в существующих анкетах: задайте окончательный список до регистрации пользователей.

## Автоматическое сжатие фото

По умолчанию новые фото анкет и диалогов автоматически уменьшаются до 1600 × 1600 пикселей с сохранением пропорций и JPEG-качеством 80. Маленькие изображения не увеличиваются; если перекодирование только увеличивает размер и уменьшение разрешения не требуется, сохраняется исходный вариант. В JPEG прозрачный фон становится белым.

Настройки находятся в `config.json` → `photoCompression`: `enabled` включает сжатие, `maxWidth` и `maxHeight` задают максимальные размеры (320–4096), `quality` — качество JPEG (40–95). После изменения настроек перезапустите бота.

Фото из Mini App сжимаются перед отправкой в Telegram. Фото, полученные ботом, обрабатываются один раз и сохраняются в `photoDirectory`; при ошибке используется исходное фото Telegram. Уже существующие фотографии не изменяются. Лимит загрузки — 20 МБ, обработки — 40 мегапикселей. Видео, GIF и стикеры не перекодируются.

Для сжатия нужен `sharp`, который устанавливается командой `npm ci`. Если optional-зависимости были пропущены, выполните `npm install --include=optional`. Без `sharp` бот продолжает работать, а дополнительное сжатие отключается.

## Подключение Mini App

1. Направьте DNS вашего домена на сервер и откройте порты 80/443.
2. В `config.json` задайте `miniApp.url`, включите `miniApp.enabled` и проверьте локальный порт.
3. Настройте nginx как обратный прокси на `http://127.0.0.1:4860` (или свой `miniApp.port`), включая заголовки `Host`, `X-Real-IP` и `X-Forwarded-Proto`. Ограничьте размер загрузки до 20 МБ. Выпустите HTTPS-сертификат для своего домена.
4. Перезапустите бота: `pm2 restart dvbot`. При старте он добавит кнопку приложения в меню Telegram.

### Пример nginx и HTTPS для Ubuntu

Замените `bot.example.org` своим доменом. В `config.json` укажите такой же адрес: `"url": "https://bot.example.org"`. DNS должен указывать на IP сервера; порты 80 и 443 должны быть доступны.

Установите nginx и плагин certbot:

```bash
sudo apt update
sudo apt install nginx certbot python3-certbot-nginx
```

Создайте `/etc/nginx/sites-available/dvbot.conf`:

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name bot.example.org;

    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:4860;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 5s;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;
        proxy_buffering off;
    }
}
```

Если изменили `miniApp.port`, замените `4860` в `proxy_pass`. Веб-сервер бота должен слушать `127.0.0.1`, а не публичный IP.

Включите сайт, проверьте конфигурацию и выпустите сертификат:

```bash
sudo ln -s /etc/nginx/sites-available/dvbot.conf /etc/nginx/sites-enabled/dvbot.conf
sudo nginx -t
sudo systemctl reload nginx
sudo certbot --nginx -d bot.example.org --redirect
sudo nginx -t
sudo certbot renew --dry-run
```

Команду `ln -s` выполните один раз. Certbot запросит email, добавит HTTPS-блок и перенаправление с HTTP на HTTPS. Затем включите `miniApp.enabled` и выполните `pm2 restart dvbot`. Проверьте `https://bot.example.org/health`.

### Включение и отключение

В `config.json` измените `miniApp.enabled` на `true` или `false` и выполните `pm2 restart dvbot`. По умолчанию приложение выключено.

Также администратор может открыть `/admin` и нажать **«Включить Mini App»** или **«Выключить Mini App»**. Настройка сохраняется в `config.json` и применяется без перезапуска. При включении URL и HTTPS уже должны быть настроены. При выключении веб-сервер останавливается, кнопка Mini App убирается из меню Telegram, а диалоги продолжают работать через обычного бота. Отдельно заданную Main Mini App в BotFather при необходимости отключите вручную.

Сервер отдаёт в `/api/public-config` только оформление, имя бота и публичные ссылки. Токены и полный конфиг через этот маршрут не публикуются.

## Автообновление без токена

По умолчанию бот раз в 60 секунд проверяет `package.json` в публичном репозитории [romanich237/dvbot](https://github.com/romanich237/dvbot), ветка `main`. Если версия выше установленной, он загружает код, устанавливает зависимости, проверяет синтаксис и перезапускает PM2-процесс `dvbot`.

```json
"github": {
  "repository": "romanich237/dvbot",
  "branch": "main",
  "autoUpdate": true,
  "checkIntervalSeconds": 60
}
```

Токен и SSH-ключ не нужны. Работает и после распаковки архива без `.git`. На сервере необходимы `git`, npm, доступ к GitHub и запущенный через PM2 бот. При запуске через `npm start` автоматический перезапуск недоступен — используйте PM2.

```bash
sudo apt install git
pm2 start ecosystem.config.cjs
pm2 save
```

Конфиг, база, фото и `.dvbot-runtime.json` не заменяются: обновляются только `src/`, `public/`, файлы npm, PM2 и README. При ошибке проверки установка не применяется; при ошибке после замены восстанавливаются предыдущие исходники. Резервное копирование рабочих данных перед обновлениями по-прежнему рекомендуется.

Чтобы отключить автоматическую установку, задайте `github.autoUpdate: false` и перезапустите бота. Проверка версий и установка через `/admin` остаются доступны. Для полного отключения проверки задайте пустой `github.repository`.

Для каждого релиза повышайте `version` в `package.json` и `package-lock.json`. Название коммита, включая **«v2 ВОЗРОЖДЕНИЕ»**, само по себе не запускает обновление. Пока в репозитории нет совместимого `package.json` и `src/main.js`, бот сообщает о недоступном JavaScript-релизе и продолжает работать.

## Структура

В корне находятся конфиг, описание проекта и файлы запуска. Серверный код собран в `src/`, интерфейс — в `public/`. База и каталог фотографий создаются при использовании; пути остаются относительно корня проекта. Папки `deploy` и `test` в сборку не включены.

| Путь | Содержимое |
| --- | --- |
| `src/main.js` | Telegram API, регистрация и логика бота |
| `src/admin.js` | Модерация, статистика, рассылки, обновления |
| `src/db.js` | SQLite и создание схемы |
| `src/web.js`, `public/` | API и интерфейс Mini App |
| `config.json` | Все настройки экземпляра |

## Решение проблем

- **Просит token/adminId:** заполните обязательные поля конфига.
- **Нет `node:sqlite`:** обновите Node.js до версии 24+.
- **Mini App не открывается:** проверьте HTTPS, DNS, nginx, порт и `miniApp.enabled`.
- **Нет расстояния:** у обоих корпусов должны быть пары `[широта, долгота]`.
- **Автообновление не работает:** проверьте доступ к публичному GitHub, наличие git/npm/PM2 и более высокой версии в `package.json`.

Рабочие данные создаются только после запуска. Для публикации сборки используйте незаполненный конфиг из архива.
