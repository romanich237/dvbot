# Telegram Dating Bot

Telegram-бот для знакомств между студентами колледжей.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте `config.py`:
   - Укажите `ADMIN_ID` - ваш Telegram ID
   - Укажите `STATS_CHANNEL_ID` - ID канала для статистики
   - Укажите `STATS_MESSAGE_ID` - ID сообщения со статистикой
   - Добавьте `BOT_TOKEN` - токен бота от @BotFather

3. Запустите бота:
```bash
python main.py
```

## Структура проекта

- `main.py` - основной файл бота с логикой обработки сообщений
- `db.py` - методы работы с базой данных
- `admin.py` - функции администратора (баны, рассылка, статистика)
- `config.py` - конфигурация (токен, ID админа, колледжи, расстояния)
- `requirements.txt` - зависимости проекта

## Функции

- Регистрация пользователей
- Просмотр анкет других пользователей
- Лайки и взаимные симпатии
- Обмен сообщениями
- Статистика профиля
- Админ-панель (баны, рассылка, статистика)

## Настройка колледжей

В `config.py` можно изменить список колледжей и расстояния между ними в `COLLEGES` и `COLLEGE_DISTANCES`.
