# Бот Дайвинчик

Бот для знакомств студентов внутри колледжа (или нескольких колледжей).

Позволяет создавать анкеты, просматривать профили других студентов, ставить лайки, обмениваться сообщениями и находить взаимные симпатии.

---

## 🚀 Возможности

- **Регистрация** – указание колледжа, имени, возраста, фото (до 3), описания и видео (опционально).
- **Просмотр анкет** – показ случайных профилей из своего колледжа или всех колледжей с учётом настроек видимости.
- **Лайки / Дизлайки** – оценка анкет, взаимные симпатии (матчи) уведомляют обоих пользователей.
- **Личные сообщения** – обмен текстом, фото, видео, голосовыми, стикерами, GIF. Поддержка уведомлений и чат-истории.
- **Управление профилем** – редактирование всех полей, скрытие анкеты, настройка видимости («только мой колледж» / «все колледжи»), скрытие из топа.
- **Поднятие анкеты (Boost)** – раз в 24 часа анкета получает приоритет в выдаче на 7 дней.
- **Статистика профиля** – количество полученных лайков, просмотров, отправленных лайков и матчей.
- **Рекламные сообщения** – показ рекламы после каждых N просмотров анкет (настраивается).
- **Отключение рекламы** – за звёзды Telegram пользователь может отключить рекламу на несколько месяцев.
- **Администрирование** – баны (с указанием причины, срока, удалением анкеты/сообщений), модераторы, рассылки, автосообщения, просмотр профилей пользователей.

## ⚙️ Установка и настройка

## Рекомендуемый провайдер [play2go.cloud](https://play2go.cloud/?ref_id=k5jH0xQ4-_g) - доступ к мини хосту для вашего бота всего за 30 рублей месяц

### 1. Клонирование репозитория

```bash
gin clone https://github.com/romanich237/dvbot
cd dvbot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Отредактируйте файл `dvbot.py`. В классе `Config` укажите:

- `TOKEN` – токен вашего бота (от @BotFather).
- `BOT_USERNAME` – username бота (без `@`).
- `ADMIN_ID` – ваш Telegram ID (узнайте у @userinfobot).
- `STATS_CHANNEL_ID` – ID канала для публикации статистики (опционально).
- `STATS_MESSAGE_ID` – ID сообщения в канале (если используется).
- `COLLEGES` – список названий колледжей.
- `COLLEGE_COORDINATES` – координаты колледжей в формате `{"название": (широта, долгота)}`.
- При необходимости измените остальные параметры (возрастные ограничения, количество фото, лимиты и т.д.).

### 4. Запуск бота

```bash
python dvbot.py
```

База данных `dating.db` и папки `photo/`, `chats/` создадутся автоматически.

## 🎮 Использование

### Основные команды

- `/start` – начать регистрацию или открыть главное меню.
- `/web` – получить одноразовый код для авторизации на сайте.
- `/help` – справка по командам.

### Главное меню

#### 👀 Смотреть анкеты

- ❤️ Лайк
- 💌 Написать сообщение
- 🚩 Пожаловаться
- ➡️ Следующая анкета
- 👎 Не интересно

#### 👤 Моя анкета

- ✏️ Редактировать профиль
- ⚙️ Настройки приватности
- 🚀 Поднять анкету

#### ✉️ Мои сообщения

Поддерживаются:

- текст;
- фото;
- видео;
- голосовые;
- стикеры;
- GIF.

#### 📊 Статистика профиля

- полученные лайки;
- просмотры;
- отправленные лайки;
- матчи.

---

## 💬 Сообщения и чаты

- Общение после лайка или открытия чата.
- Поддерживаются все основные типы медиа.
- Приходит уведомление с кнопкой «Ответить».
- Генерируется изображение чата при наличии Pillow.

- На анкету — кнопка 🚩.

## 🛠 Администрирование

Доступ имеет пользователь с `ADMIN_ID`.

### Команды модератора

- `/help`
- `/view <user_id>`
- `/ban <user_id>`
- `/unban <user_id>`
- `/banlist`
- `/admin`

### Команды администратора

- `/stats`
- `/photo`
- `/add_moderator <id>`
- `/remove_moderator <id>`
- `/list_staff`
- `/broadcast`
- `/auto`

### Управление банами

- Банлист.
- Поиск по ID.
- Разбан пользователей.

---

## 📊 Автоматическая статистика

Если указаны `STATS_CHANNEL_ID` и `STATS_MESSAGE_ID`, бот обновляет сообщение в канале каждые `STATS_UPDATE_INTERVAL_SEC` секунд.

Отображается:

- пользователи по колледжам;
- всего пользователей;
- регистрации за сегодня.
