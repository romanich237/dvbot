# Дайвинчик Бот

Бот для знакомств студентов колледжей через Telegram.

## Быстрый старт

Сначала установи зависимости:
```bash
pip install -r requirements.txt
```

Потом открой `config.py` и укажи:
- `ADMIN_ID` - твой Telegram ID
- `STATS_CHANNEL_ID` - ID канала где будет статистика
- `STATS_MESSAGE_ID` - ID конкретного сообщения со статистикой
- `BOT_TOKEN` - токен от @BotFather

Запуск:
```bash
python main.py
```

## Что внутри

`main.py` - вся основная логика бота, обработка сообщений и все такое  
`db.py` - работа с базой данных  
`admin.py` - админка, баны и рассылки  
`config.py` - настройки (токены, колледжи, расстояния)  
`requirements.txt` - библиотеки

## Что умеет бот

### Обычные пользователи

Создаешь профиль с фото и описанием, указываешь свой колледж и возраст. Можешь смотреть анкеты других - либо только своего колледжа, либо всех. Ставишь лайки, если взаимно - получаешь уведомление о матче и можешь начинать переписку.

В чатах работают все типы сообщений - текст, фото, видео, голосовые, стикеры, GIF. Есть история всех твоих переписок, можно посмотреть сводку чата в виде картинки.

Важно: медиафайлы (фото, видео, голосовые) хранятся на серверах Telegram в течение года, после чего автоматически удаляются. Текстовые сообщения и другая информация сохраняются в базе данных бота.

В настройках профиля можно менять любое поле, скрыть анкету от других или изменить охват поиска. Поднять анкету в топ можно раз в сутки. Есть статистика - сколько лайков, просмотров и матчей.

### Админка

В админ-панели доступна статистика по колледжам - сколько зарегистрировалось, сколько лайков, матчей, банов. Она автоматически обновляется в канале каждые 3 минуты (настраивается в `STATS_UPDATE_INTERVAL_SEC`).

Можно банить пользователей на время или навсегда, с удалением профиля и сообщений при необходимости. Есть список всех активных банов и поиск по ID. Разумеется, можно разбанить.

Рассылка работает для всех пользователей одновременно, учитывает тех кто отключил рассылку. Можно настроить автосообщение которое будет показываться каждые 5 просмотров анкет - удобно для рекламы. Есть функция супер-лайка - автоматически лайкнуть всех пользователей от имени админа.

## Про колледжи

Список колледжей и расстояния между ними настраиваются в `config.py` через `COLLEGES` и `COLLEGE_DISTANCES`. Индексы колледжей задаются константами типа `COLLEGE_0`, `COLLEGE_1` и так далее для удобства.
